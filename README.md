# 📌 Student Task Manager (CLI Project)

A beginner-friendly Command Line Interface (CLI) application built using **Python** to manage daily study or personal tasks efficiently.

---

# 🚀 Project Overview

The **Student Task Manager** allows users to:

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks permanently using JSON storage

This project demonstrates core Python programming concepts along with real-world software workflow practices.

---

# 🛠️ Tech Stack

- **Language:** Python 3
- **Interface:** Command Line (CLI)
- **Storage:** JSON File
- **IDE Used:** VS Code
- **Version Control:** Git & GitHub
